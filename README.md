## IP/Mac Discovery written in C++

## :rocket: Starting

1. clone the repo
```bash
git clone https://github.com/hellowaste344/IP-scanner.git
cd IP-scanner
```

2. Specify target and ports.
```py
python cmd.py --target <target ip address> -p <ports to scan> 
```
